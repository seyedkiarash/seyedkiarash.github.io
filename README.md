# سایت شخصی و رزومهٔ آکادمیک

سایت ایستای دوزبانه (فارسی / English) برای GitHub Pages — بدون نیاز به نصب یا build.

## صفحات
| فایل | محتوا |
|---|---|
| `index.html` | معرفی، تحصیلات، پروژه‌های منتخب، افتخارات، مهارت‌ها |
| `projects.html` | همهٔ پروژه‌ها با فیلتر برچسب |
| `project.html?id=...` | صفحهٔ جزئیات هر پروژه (توضیح، تصاویر، فایل‌ها، لینک‌ها) |
| `activities.html` | دستیار آموزشی، کارگاه‌ها، انجمن‌ها و … |
| `cv.html` | رزومهٔ خلاصه، قابل چاپ و ذخیره به PDF |

## ویرایش محتوا
همهٔ محتوا فقط در **`assets/js/content.js`** است. متن‌های دوزبانه به شکل `{ fa: "...", en: "..." }` نوشته می‌شوند.

- تصاویر → `assets/img/`
- فایل‌ها (PDF، اسلاید، گزارش) → `assets/files/`
- عکس پروفایل: مقدار `photo` را بگذارید، مثلاً `"assets/img/profile.jpg"`
- برای افزودن پروژه، یک بلوک از آرایهٔ `projects` را کپی و ویرایش کنید (`id` یکتا و انگلیسی باشد).

## انتشار روی GitHub Pages
1. در GitHub یک مخزن (repository) **عمومی** با نام دقیق `USERNAME.github.io` بسازید (USERNAME = نام کاربری شما).
2. روی **Add file → Upload files** بزنید و **محتوای داخل** این پوشه (نه خود پوشه) را بکشید و رها کنید، سپس **Commit changes**.
3. در **Settings → Pages**، بخش *Source* را روی **Deploy from a branch**، شاخه `main` و پوشه `/ (root)` بگذارید.
4. پس از یکی‌دو دقیقه سایت روی `https://USERNAME.github.io` در دسترس است.

## مشاهدهٔ محلی
فایل `index.html` را مستقیم در مرورگر باز کنید، یا:
```
python3 -m http.server
```

فونت‌ها (Vazirmatn، Inter، Source Serif 4) داخل `assets/fonts` قرار دارند و سایت به سرویس خارجی وابسته نیست.
